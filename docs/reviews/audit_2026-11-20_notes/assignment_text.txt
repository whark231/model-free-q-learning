SUGGESTED TERM PROJECT 3
Model Free Q Learning and Optimal Portfolio Choice
with Nine Assets
Fall 2026
This project asks whether a model-free reinforcement learning agent can learn a theoretically optimal
portfolio using only realized returns. You will calibrate a controlled nine-asset environment from traded
ETFs, solve the corresponding mean-variance problem, train a Q-learning agent without revealing the
return moments, and measure how closely the learned policy approaches the best feasible benchmark.
Central Research Question
Can a model-free learning algorithm recover a near-optimal portfolio allocation when it observes realized
rewards but does not know expected returns or covariances?
The project contrasts economic theory with model-free machine learning in a controlled setting. A strong
analysis should separate:
• The continuous theoretical optimum from the best portfolio available on the discrete action grid
• Learning error from approximation error created by portfolio-weight discretization
• Calibration of the synthetic environment from evaluation on fresh simulated returns
• Statistical convergence from economically meaningful convergence
Project Objectives
By completing the project, you will:
• Construct and document a nine-ETF return dataset
• Estimate a mean vector and covariance matrix and treat them as the ground truth of a synthetic
environment
• Compute theoretical optimal portfolios under clearly stated constraints
• Design a feasible high-dimensional portfolio action set
• Implement model-free Q-learning using simulated realized returns only
• Evaluate accuracy, convergence speed, robustness, and computational tradeoffs

Required Baseline Constraint
Use a long-only, fully invested portfolio as the primary nine-asset specification. This restriction creates a
finite and interpretable action space for tabular Q-learning.
Every portfolio weight must be nonnegative, and the nine weights must sum to one.
Bounded Shorting and Leverage Extension
As a bonus extension, allow bounded short positions or leverage. State the lower and upper bounds and
apply the same bounds to both the theoretical optimizer and the learning agent.
Each weight must lie within its stated lower and upper bounds, and the nine weights must still sum to one.
For every specification, report two benchmarks: the continuous optimum and the best portfolio available in
the agent's discrete action set. This separates the loss caused by discretization from the loss caused by
incomplete learning.
Part III Reinforcement Learning Design
State
The required baseline is stateless because the synthetic returns are independent and identically
distributed. If you add state variables, they must be observable at the decision date, and you must explain
why they contain useful information in the simulated environment.
Action Space
Each action is a feasible nine-component portfolio-weight vector. Because the weights sum to one, only
eight components are independent. A fine Cartesian grid becomes very large, so action-space design is a
central research decision.

You may instead use a fixed library of randomly sampled feasible portfolios. If you do, generate it
independently of the calibrated moments, fix the random seed, use the same library in every comparable
run, and report its size and coverage. Do not insert the theoretical optimum into the action set.
Reward
Choose a reward that matches the theoretical objective. The recommended approach is an episodic
realized mean-variance reward: for each selected portfolio, simulate a short batch of returns and compute
its realized mean minus one-half times risk aversion times its realized variance.

Part IV Training and Convergence
Train the agent on simulated returns from the calibrated environment. Evaluate it on new simulated draws
that were not used to update Q-values. Run multiple random seeds so that conclusions do not depend on
a single training path.
You must define convergence before examining the final results. Possible criteria include:
• The greedy action remains unchanged for a prespecified number of episodes
• The maximum change in Q-values falls below a stated tolerance
• A moving average of portfolio weights or rewards stabilizes
• The learning gap relative to the best discrete action falls below a prespecified threshold
Report how many observations and episodes are required to reach the criterion, how often convergence
occurs across seeds, and whether the result changes with the size of the action set.

Part VI Robustness and Research Challenges
Conduct at least two robustness checks, including one that changes the action-space design and one that
changes an economic or statistical assumption.
• Coarser versus finer portfolio-weight grids
• Different risk-aversion parameters
• Alternative calibration windows
• Sample covariance versus a shrinkage covariance estimate
• Different training budgets, episode lengths, and random seeds
• Gaussian returns versus a fat-tailed return distribution
Your discussion should explicitly address:
• Estimation error in expected returns and covariances
• Conditioning and numerical stability of the covariance matrix
• The curse of dimensionality in a nine-asset action space
• Discretization error and possible benchmark leakage
• Consistency between the reward and theoretical objective
• The limits of learning from a stationary simulated environment
