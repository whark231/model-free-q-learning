# Report drafts

**TL;DR / In plain terms:** the submitted report is `docs/report/REPORT.md` and
`REPORT.pdf`. This folder keeps the earlier versions and the notes on what
changed between them, as a record of how the report was written. Nothing here
is needed to read or rebuild the report.

| File | What |
|---|---|
| `REPORT_SKELETON.md` | Outline written before the report: claims, numbers with their source files, figures and caveats per section (2026-11-20 to 11-23) |
| `REPORT_v1.md`, `REPORT_v1.pdf` | First full draft (Albert, 2026-11-24, PR #51) |
| `REPORT_v2_AA.md`, `REPORT_v2_AA.pdf` | Second draft with Albert's markup applied (2026-11-25) |
| `CHANGES_v1_to_v2.md` | What changed from v1 to v2 |
| `CHANGES_v2_to_final.md` | What changed from v2 to the submitted report, including deliberate deviations from the markup and fixes from the independent review |

The drafts were moved here on 2026-11-26, when the final draft
(`REPORT_final.md`) became `docs/report/REPORT.md`. Their figure paths
(`figures/...`) are relative to `docs/report/`, so they no longer rebuild from
this folder; the PDFs are the record. Earlier text in these files that names
`REPORT_final.md` means today's `REPORT.md`, and `REPORT.md` there means v1.
